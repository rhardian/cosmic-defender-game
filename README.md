A fast-paced space shooter where you defend Earth from waves of alien invaders. Features multiple enemy types, power-ups, particle effects, and progressive difficulty.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in your browser.

## Controls

- **Arrow Keys / WASD** - Move your ship
- **SPACE** - Shoot

## Features

- Original pixel-art style graphics
- Three enemy types: Basic, Fast, Tank
- Power-ups: Extra Life, Rapid Fire
- Particle explosion effects
- Progressive difficulty with levels
- HUD showing score, level, and lives
- Complete game loop: Title → Play → Game Over → Restart
